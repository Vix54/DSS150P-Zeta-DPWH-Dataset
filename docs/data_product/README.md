# Data Product Sample

A small, reviewable copy of the pipeline's final outputs, so the curated product and the analytics can be inspected without running the pipeline. The full data stays git-ignored under `data/`.

Generated by:

```bash
python -m src.cli analyze
python -m src.cli sample
```

| File | Contents |
| --- | --- |
| `sample_contracts.csv`, `sample_contracts.parquet` | 1,000 curated contracts drawn at random with `random_state=42`, all 43 curated columns, sorted by `contract_id` |
| `region_population.csv` | The curated region population table (PSA OpenSTAT, joined on the PSGC region code) |
| `insights.md` | The analysis text, generated from the computed numbers by `analyze` |
| `analytics_metrics.json` | Every computed figure: summary counts, regional delay rates, per-capita values and the exploratory classifier's metrics |
| `charts/` | The five PNG charts written by `analyze` (status counts, delay rate by region, cost distribution, feature importance, delayed contracts per 100,000 people) |
| `sample_manifest.json` | The curated run, the SHA-256 of the full curated file, row counts, seed and columns |
| `SHA256SUMS` | SHA-256 of every file in this folder; check with `sha256sum -c SHA256SUMS` from inside it |

Notes for reading the sample:

- Column meanings are in `docs/data_dictionary.md` and the curated product in `docs/curated_data_product.md`.
- `project_cost` is the source `budget`, whose meaning is inconsistent in the source; use `abc_php`, `award_amount_php` and `award_to_abc_pct` for budget comparisons.
- The delay flag and the classifier describe one snapshot of the source (delay rule as of 2026-01-22). The classifier is exploratory: it is not a forecast of future delays and does not establish causes.
- A sample of 1,000 rows is for inspection only; the figures in `insights.md` are computed on all curated contracts.
